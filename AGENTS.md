# VeriLens Frontend Design Rules

These guidelines keep the frontend consistent, modern, and polished across the React + Vite app.

Preferred stack:

* React
* Tailwind CSS
* shadcn/ui-inspired component patterns

UI Guidelines:

* Use card-based layouts for dashboards and content sections
* Use a consistent spacing scale: 4, 8, 12, 16, 24, 32
* Use rounded corners and gentle elevation
* Prefer subtle borders and soft shadows instead of heavy shadows
* Keep typography clean, readable, and well scaled
* Use dashboard-style analytics cards and data-focused layouts
* Ensure responsive layouts for desktop and mobile
* Maintain professional enterprise styling with calm, neutral tones
* Use Tailwind utility classes for spacing, layout, and visual rhythm
* Build reusable semantic components rather than ad-hoc styles

Components should resemble shadcn/ui components even if not directly imported.

Design approach:

* Use a restrained palette with one strong accent color
* Keep visual hierarchy clear with surface and background contrast
* Favor whitespace and clarity over clutter

Avoid:

* Bright gradients
* Excessive animations
* Heavy glassmorphism
* Inconsistent spacing
* Random color palettes

The overall aesthetic should resemble:

* Vercel
* Linear
* Notion
* Stripe Dashboard
* Modern SaaS products
